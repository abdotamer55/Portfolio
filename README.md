# Abdelrahman Tamer portfolio

Responsive static portfolio with six featured case studies, project filters, dark/light themes, and a corrected fourth-year CV.

## Preview
Open index.html in a current browser. No build or install is required.

## Upload to GitHub
Extract this ZIP first. Open the Portfolio repository, choose Add file > Upload files, then select ALL FILES INSIDE this folder. Do not upload the ZIP itself or the enclosing folder. The files belong at the repository root, beside index.html. Commit directly to main to update the existing site source.

Keep the portfolio-*.webp images and portfolio-favicon.svg beside index.html. Their names match the references in the source.

Abdelrahman-Tamer-CV.pdf is the downloadable CV used by the new site. The copy named Abdelrahman_Tamer_Professional_CV.pdf also replaces the previous CV at its old path, so older download links get the corrected document. Both contain the same approved fourth-year correction.
